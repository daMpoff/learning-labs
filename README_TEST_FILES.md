# Тестовые файлы для проверки VirusTotal

## EICAR тестовый файл

Файл `test-virus.txt` содержит стандартную EICAR тестовую строку.

### Что такое EICAR?

EICAR (European Institute for Computer Antivirus Research) - это стандартный тестовый файл, который используется для проверки работы антивирусных программ.

**Важно:**
- ✅ Это НЕ настоящий вирус
- ✅ Файл полностью безопасен
- ✅ Не причиняет вреда системе
- ✅ Все антивирусы распознают его как тестовую угрозу

### Содержимое файла:
```
X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*
```

### Использование:

1. Загрузите файл `test-virus.txt` через веб-интерфейс приложения
2. Большинство антивирусов должны определить его как вредоносный
3. Это позволит протестировать отображение результатов с детектами

### Ожидаемый результат:

При сканировании через VirusTotal большинство антивирусов должны показать:
- **Категория:** `malicious` или `suspicious`
- **Результат:** Обычно "EICAR-Test-File" или похожее название
- **Статистика:** Должно быть несколько детектов в категории "Вредоносное"

### Примечание:

Если ваш локальный антивирус удалит файл при создании - это нормально. Файл можно пересоздать или временно отключить защиту для тестирования.
