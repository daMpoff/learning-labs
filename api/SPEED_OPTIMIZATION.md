# Оптимизация скорости парсинга

## Сравнение методов

### Синхронный парсер (старый)
- ⏱️ **Скорость**: ~1-3 секунды на товар
- 📊 **Для 100 товаров**: ~2-5 минут
- 📊 **Для 500 товаров**: ~10-30 минут
- 🔄 **Параллелизм**: Нет (последовательная обработка)

### Асинхронный парсер (новый) ⚡
- ⏱️ **Скорость**: ~0.1-0.3 секунды на товар
- 📊 **Для 100 товаров**: ~10-30 секунд
- 📊 **Для 500 товаров**: ~1-3 минуты
- 🔄 **Параллелизм**: До 15 одновременных запросов

## Ускорение: **5-10 раз быстрее!**

## Как использовать

### Через Swagger UI

1. Откройте http://localhost:8000/docs
2. Найдите `POST /api/parser/start`
3. Параметры:
   - `max_pages`: количество страниц (или null для всех)
   - `use_async`: `true` (по умолчанию) - быстрый режим
4. Нажмите "Execute"

### Через curl

```bash
# Быстрый режим (асинхронный) - РЕКОМЕНДУЕТСЯ
curl -X POST "http://localhost:8000/api/parser/start?max_pages=5&use_async=true"

# Медленный режим (синхронный) - для отладки
curl -X POST "http://localhost:8000/api/parser/start?max_pages=5&use_async=false"
```

## Технические детали

### Асинхронный парсер использует:
- **httpx** - асинхронный HTTP клиент
- **asyncio** - параллельная обработка запросов
- **Semaphore** - ограничение одновременных запросов (15 по умолчанию)

### Преимущества:
1. ✅ Параллельная обработка товаров
2. ✅ Меньше задержек между запросами
3. ✅ Эффективное использование сетевых ресурсов
4. ✅ Автоматическое управление соединениями

### Настройка скорости

В `nix_parser_async.py` можно изменить:

```python
parser = NixParserAsync(
    delay_min=0.3,        # Минимальная задержка (секунды)
    delay_max=0.8,        # Максимальная задержка (секунды)
    max_concurrent=15     # Количество одновременных запросов
)
```

**Внимание**: Не ставьте `max_concurrent` слишком высоким (более 20), чтобы не перегрузить сервер NIX.ru!

## Рекомендации

1. **Для теста**: `max_pages=1`, `use_async=true`
2. **Для полного парсинга**: `max_pages=null`, `use_async=true`
3. **Если возникают ошибки**: попробуйте `use_async=false` (медленнее, но стабильнее)
