# Быстрый старт парсинга

## Шаг 1: Установить зависимости

```bash
cd api
pip install -r requirements.txt
```

## Шаг 2: Запустить сервер

```bash
uvicorn main:app --reload
```

Вы увидите:
```
INFO:     Uvicorn running on http://127.0.0.1:8000
✅ База данных инициализирована
```

## Шаг 3: Запустить парсинг

### Вариант A: Через браузер (самый простой)

1. Откройте: http://localhost:8000/docs
2. Найдите `POST /api/parser/start`
3. Нажмите "Try it out"
4. В поле `max_pages` введите `1` (для теста) или оставьте пустым (все страницы)
5. Нажмите "Execute"
6. **Смотрите логи в консоли**, где запущен сервер!

### Вариант B: Через curl

```bash
# Тестовый парсинг (1 страница)
curl -X POST "http://localhost:8000/api/parser/start?max_pages=1"

# Полный парсинг (все страницы)
curl -X POST "http://localhost:8000/api/parser/start"
```

## Проверка статуса

Откройте в браузере или через curl:
```bash
curl http://localhost:8000/api/parser/status
```

## Проверка результатов

```bash
# Количество смартфонов
curl http://localhost:8000/api/parser/smartphones/count

# Список смартфонов
curl http://localhost:8000/api/parser/smartphones?limit=5
```

## Важно!

- **Логи выводятся в консоль**, где запущен `uvicorn`
- Парсинг выполняется в фоновом режиме
- Данные сохраняются в `smartphones.db` (SQLite)
- Для теста используйте `max_pages=1`
- Для полного парсинга оставьте `max_pages` пустым

## Если что-то не работает

1. Проверьте, что сервер запущен
2. Проверьте, что все зависимости установлены
3. Смотрите ошибки в консоли
4. Проверьте интернет-соединение (нужен доступ к nix.ru)
