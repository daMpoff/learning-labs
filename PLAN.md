## 3. Детальная реализация ключевых компонентов

### 3.1. Алгоритм TOPSIS (псевдокод)

```
1. Создать матрицу решений D (m альтернатив × n критериев)
2. Нормализовать матрицу:
   rij = xij / sqrt(Σ(xij²)) для каждого столбца j
3. Взвесить нормализованную матрицу:
   vij = wj * rij, где wj - вес критерия j
4. Определить идеальные решения:
   PIS = (v1+, v2+, ..., vn+) где vj+ = max(vij) для max-критериев
                                vj+ = min(vij) for min-критериев
   NIS = (v1-, v2-, ..., vn-) где vj- = min(vij) для max-критериев
                                vj- = max(vij) для min-критериев
5. Вычислить расстояния:
   Si+ = sqrt(Σ(vij - vj+)²) - расстояние до PIS
   Si- = sqrt(Σ(vij - vj-)²) - расстояние до NIS
6. Вычислить относительную близость:
   Ci = Si- / (Si+ + Si-)
7. Ранжировать альтернативы по убыванию Ci
```

### 3.2. Структура данных для парсинга

Параметры смартфона (минимум 7):
1. **Цена** (количественный, min) - рубли
2. **Размер экрана** (количественный, max) - дюймы
3. **RAM** (количественный, max) - ГБ
4. **Память** (количественный, max) - ГБ
5. **Батарея** (количественный, max) - мАч
6. **Камера** (количественный, max) - МП
7. **Рейтинг** (количественный, max) - баллы
8. **Процессор** (качественный → количественный) - рейтинг производительности
